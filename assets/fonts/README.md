# Document fonts

Unmodified Liberation Sans, Serif and Mono fonts, with Regular, Bold, Italic and Bold Italic
faces. Distributed under the SIL Open Font License 1.1; see LICENSE-Liberation.txt.
The editor loads these files on demand, and installation includes the fonts and license.
Document text stores family/style choices and generated outlines, keeping saved artwork and
exports independent of system font availability. The editor UI retains its existing Noto Sans font.
